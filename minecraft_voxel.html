▸ About
A 48×32×48 voxel world generated from fractal noise with scattered trees. Nine block types in the hotbar; pick existing blocks with middle-click. Mesh build is chunked (16×32×16) so editing one corner doesn't re-mesh the whole world. Targeting uses voxel-DDA raycasting for sub-cell precision.
