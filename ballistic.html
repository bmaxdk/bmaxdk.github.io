// 3-DOF Throw Simulator //
▸ Mission Briefing
Pilot a 3-DOF planar manipulator. Wind up the arm, then release the ball on a ballistic trajectory to hit incoming targets. Tip velocity is computed live via Jacobian: vtip = J(θ) · ω. Faster tip means farther throw — but timing matters more than raw power. Trajectory predictor is overlaid in cyan; toggle T if you want it off.
▸ Controls
AD Shoulder torque (θ₁)
SW Elbow torque (θ₂)
QE Wrist torque (θ₃)
Space Release ball
R Reset arm pose
T Toggle trajectory predictor
Y Toggle AI mode (built-in or custom)
P Pause
M Mute SFX
▸ AI Mode
Press Y or click AI to engage the built-in analytical controller. It PD-controls to a wind-up pose, swings under bang-bang torques, forward-simulates the ballistic trajectory each frame, and releases when the predicted path passes within target.r + ball.r of the (lead-projected) target.

To plug in your own trained policy, set game.policy = (obs) => ({ actions, release }) from the dev console. obs contains joint angles, ω, tip pose, J·ω, and target state. See the comment block above the AnalyticAI class in the source for the full schema.
